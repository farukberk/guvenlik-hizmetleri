# Güvenlik Hizmetleri Uygulaması

Mendix projesi, özel bileşen kaynakları ve yardımcı analiz dokümanları.

- `GuvenlikUygulamasi/`: Mendix uygulaması. Studio Pro ile `GuvenlikUygulamasi.mpr` dosyasını açın.
- `Dokumanlar/`: Analizler, HTML prototipi, PDF belgeleri ve ekran görüntüleri.
- `WidgetKaynaklari/`: Özel GhFilePreview bileşeninin kaynakları.

## İndirme

Git LFS kurulu olmalıdır. Depoyu klonladıktan sonra `git lfs pull` çalıştırın.
Büyük Mendix modülleri Git LFS ile saklanır.
